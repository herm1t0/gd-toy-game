# AGENTS.md

Godot 4 project. Game code lives at the repo root (`project.godot`); `addons/godot_ai` is a third-party plugin, not project code.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `herm1t0/gd-toy-game`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
